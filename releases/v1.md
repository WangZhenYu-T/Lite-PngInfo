## English

**Download `Lite-PngInfo-v1-Windows-x64.zip` for Windows 10/11, 64-bit.** This historical BunnyInfo release retains its original archive and executable names.

1. Extract the entire ZIP to a writable folder.
2. Double-click **Lite-PngInfo.exe**. Your browser opens automatically.
3. Close the small launcher window to stop the application.

**No Python installation, dependency setup, or terminal commands needed.** Keep `_internal` beside the executable; do not run directly inside the ZIP. The UI is currently in Chinese.

v1 is the original NAI metadata reader with categorized/JSON views, preview, reset, and SQLite favorites. Application code: `ab6d87c824a9762edfe30e986509389d6c309ea3` (the original v1 tag). The release adds a shared desktop launcher and bundled runtime; it does not backport v2 parsers. Use v2 for A1111/Forge classification and improved JSON handling.

Favorites are stored next to the executable in `data/favorites.sqlite3`. Back up and move `data/` while the app is closed. Port 8765 is preferred; if occupied, the launcher chooses a free localhost port. The app is unsigned, so Windows may show a publisher/reputation warning. Check the included `VERSION.txt`, dependency notices, and checksum attachment if needed.

The automatically generated **Source code** downloads below are developer archives, not the ready-to-run application. Linux/macOS binaries are not provided.
