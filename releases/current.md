## 简体中文

下载 **BunnyInfo-版本号-Windows-x64.zip**，完整解压后双击 **BunnyInfo.exe**，浏览器自动打开。关闭小启动窗口即可退出。无需安装 Python、依赖或使用命令行，请保留 `_internal` 文件夹。

本次为 BunnyInfo 品牌更新：统一网页、启动器、Windows exe/浏览器图标与包名，PNG 解析和收藏数据库结构保持 v2 行为。尚未实现 v3 的模型盘点与 Civitai 查询。

升级前退出程序并备份 `data/`，把整个 `data/` 复制到新程序旁即可保留收藏。旧收藏首次升级写回前会生成数据库备份；解除收藏不影响旧备份。

程序未签名，Windows 可能提示未知发布者。支持 Windows 10/11 x64，附 SHA-256 校验。自动生成的 Source code 是源码，普通用户请选择 Windows ZIP。

## English

Download **BunnyInfo-VERSION-Windows-x64.zip**, extract the entire archive and open **BunnyInfo.exe**. Your browser opens automatically; close the launcher window to exit. No Python or dependency installation is needed. Keep `_internal` beside the executable.

This is a BunnyInfo branding update: page/launcher names, Windows executable/browser icons and package names are unified. PNG parsing and the favorites schema retain v2 behavior. v3 model inventory and Civitai lookup are not implemented.

Before upgrading, close the app, back up `data/`, and copy the entire folder beside the new executable. A database backup is made before old favorites are upgraded. Deleting a favorite does not change old backups.

Unsigned Windows 10/11 x64 build; SHA-256 checksums are provided. The automatic Source code downloads are developer archives; choose the Windows ZIP for the ready-to-run app.
