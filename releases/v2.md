## English

**Download `Lite-PngInfo-v2-Windows-x64.zip` for Windows 10/11, 64-bit. This is the recommended version.**

1. Extract the entire ZIP to a writable folder.
2. Double-click **Lite-PngInfo.exe**. Your browser opens automatically.
3. Close the small launcher window to stop the application.

**No Python installation, dependency setup, terminal commands, account, or API key needed.** Keep `_internal` beside the executable; do not run directly inside the ZIP. The UI is currently in Chinese.

### Changes from v1

- NAI character prompts and model information; A1111/Forge prompts, settings, recorded models, LoRAs, and hashes.
- Minimal ComfyUI classification: simple, unambiguous prompts only. Complex graph data remains in JSON; drag the PNG into ComfyUI to import its embedded workflow.
- Formatted JSON fields, exact original-text copying, duplicate/compressed/post-image text preservation, and exact large integer seeds.
- Explicit metadata-free image states and source labels in favorites.
- Safe file/reset state handling; Windows regression tests fixed and all four CI combinations verified before publication.

### Existing favorites

Close the old application and back up its `data/` folder. Copy `data/` beside the new executable before opening v2. Original images, IDs, and creation dates are preserved; old favorites update when opened. Before the first write-back, the app creates `data/favorites.before-v2.sqlite3`. Deleting a favorite changes the active database, not that backup. Retain an original database copy for returning to v1.

Port 8765 is preferred; if occupied, a free localhost port is used. The app is unsigned, so Windows may show a publisher/reputation warning. The package includes source/packaging commit identifiers, dependency notices, per-file checksums, and a separate archive checksum.

The automatic **Source code** links are developer archives, not the ready-to-run app. Linux/macOS binaries, the v3 favorite viewer, and v4 Civitai lookup are not included.

## 简体中文

**Windows 10/11（64 位）用户请下载 `Lite-PngInfo-v2-Windows-x64.zip`，推荐使用此版本。**

1. 完整解压到可写目录。
2. 双击 **Lite-PngInfo.exe**，浏览器自动打开。
3. 关闭小启动窗口即可退出。

**无需安装 Python、依赖，无需命令行、账号或 API 密钥。** 保留 `_internal` 文件夹，不要直接在 ZIP 中运行。界面目前使用中文。

### 相比 v1 的变化

- NAI 角色提示词与模型信息；A1111/Forge 提示词、生成参数、已记录的模型、LoRA 和哈希。
- ComfyUI 精简分类，只提取简单明确的提示词；复杂工作流在 JSON 查看，或直接拖入 ComfyUI 导入内嵌工作流。
- JSON 按字段格式化并准确复制原文，保留重复、压缩、后置文本与大整数 seed 精度。
- 无元信息图片的明确空状态，收藏显示来源。
- 换图/重置状态处理；修复 Windows 测试，并在发布前验证四组 CI。

### 已有收藏升级

先退出旧应用并备份 `data/`，把 `data/` 复制到新版 exe 旁，再启动 v2。原图、ID 和创建时间保留，旧收藏打开时更新分类；首次写回前创建 `data/favorites.before-v2.sqlite3`。解除收藏只修改当前数据库，不影响备份。需要回到 v1 时保留原数据库的独立副本。

优先使用 8765，端口被占用时自动选择空闲本机端口。程序未做代码签名，Windows 可能提示发布者或信誉警告。包内包含应用/打包提交来源、依赖许可、逐文件校验和单独的压缩包校验附件。

自动生成的 **Source code** 供开发者使用，普通用户请选择带 **Windows-x64.zip** 名称的附件。尚未提供 Linux/macOS 二进制包，也未包含 v3 收藏查看器和 v4 Civitai 查询。
